# Data

Place the official predefined UNSW-NB15 CSV partition here:

- `data/raw/UNSW_NB15_training-set.csv`
- `data/raw/UNSW_NB15_testing-set.csv`

If the files are absent and `auto_download_mirror: true`, the scripts download a SHA-256-verified public mirror of the same predefined CSV files. The canonical dataset page remains:

https://research.unsw.edu.au/projects/unsw-nb15-dataset

Raw CSV files are ignored by default because they are third-party data.
